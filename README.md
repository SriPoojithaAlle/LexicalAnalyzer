# Lexical Analyzer & Token Counter

## 1. Title

**Lexical Analyzer & Token Counter**

A C program that reads C source code, identifies different types of tokens, displays each token with its type, and counts the total number of tokens in each category.

---

## 2. Objective

The objective of this project is to develop a Lexical Analyzer that reads a C source-code file and identifies and counts different types of tokens.

The program classifies tokens into the following categories:

- Keywords
- Identifiers
- Operators
- Constants
- String Literals
- Separators
- Comments
- Special Symbols

The project is implemented using the C programming language.

---

## 3. Problem Statement

Design and implement a Lexical Analyzer in C that reads C source code as input and identifies the different types of tokens present in it.

The program should classify each token as a keyword, identifier, operator, constant, string literal, separator, comment, or special symbol.

The program should display each identified token along with its token type and finally calculate and display the count of each type of token and the total number of tokens.

---

## 4. Algorithm

### Step 1
Start the program.

### Step 2
Define a list of C language keywords such as `int`, `float`, `if`, `else`, `return`, `while`, `for`, etc.

### Step 3
Open and read the C source-code input file.

### Step 4
Scan the source code character by character until the end of the file.

### Step 5
If the character is whitespace, ignore it and move to the next character.

### Step 6
If the character is an alphabet or underscore (`_`):

- Read all following characters that are alphabets, digits, or underscores.
- Form a complete word.
- Check whether the word exists in the keyword list.
- If it is a keyword, classify it as `Keyword`.
- Otherwise, classify it as `Identifier`.
- Increment the corresponding counter and total token count.

### Step 7
If the character is a digit:

- Read the complete numeric value.
- Classify it as a `Constant`.
- Increment the constant counter and total token count.

### Step 8
If the character is a double quote (`"`):

- Read characters until the closing double quote is found.
- Classify the complete sequence as a `String Literal`.
- Increment the string literal counter and total token count.

### Step 9
If the character is an operator such as `+`, `-`, `*`, `/`, `=`, `<`, `>`, etc.:

- Check whether it forms a two-character operator such as `==`, `<=`, `>=`, or `!=`.
- Classify it as an `Operator`.
- Increment the operator counter and total token count.

### Step 10
If the character is a separator such as `;`, `,`, `(`, `)`, `{`, `}`, `[`, or `]`:

- Classify it as a `Separator`.
- Increment the separator counter and total token count.

### Step 11
If the characters represent a comment:

- Identify single-line comments beginning with `//`.
- Identify multi-line comments beginning with `/*` and ending with `*/`.
- Classify them as `Comment`.
- Increment the comment counter.

### Step 12
If the character does not belong to any supported category, classify it as a `Special Symbol`.

### Step 13
Display each identified token along with its token type.

### Step 14
Display the final token count for:

- Keywords
- Identifiers
- Operators
- Constants
- String Literals
- Separators
- Comments
- Special Symbols
- Total Tokens

### Step 15
Close the input file and stop the program.

8. Token Classification
Token Type	Description	Examples
Keyword	Reserved words of the C language	int, float, if, return
Identifier	Names of variables, functions, and other user-defined elements	sum, average, printf
Operator	Symbols used to perform operations	+, -, *, /, =, >
Constant	Numeric or character values	10, 50, 2.0
String Literal	Text enclosed within double quotes	"Pass"
Separator	Symbols used to separate different parts of a program	(, ), {, }, ;, ,
Comment	Text written for explanation and ignored during compilation	// Calculate average
Special Symbol	Symbols that do not belong to the other token categories	#, @

10. Conclusion
The Lexical Analyzer program was successfully implemented in C to identify and classify different types of tokens present in C source code.

This project demonstrates the basic working principle of a lexical analyzer, which is an important phase of a compiler.
